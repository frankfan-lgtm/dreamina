Dreamina V2

AI 通用多智能体世界模拟引擎 — 设计理念与产品方案

一、我们在做什么

一句话：用户描述一个世界，AI 自动生成角色和规则，每个角色作为独立智能体自主行动，故事从规则中自然涌现。

不是 AI 写剧本，是 AI 演活人。

三大应用场景：

场景示例用户价值
叙事模拟哈利波特毕业后的故事、流浪地球三以上帝/跟随视角看 AI 演绎的故事，可随时干预
群体预测模拟股票市场多方博弈、球赛推演多个"分析师 Agent"各自判断，涌现群体智慧
UGC 创作用户自定义世界观和角色新一代内容创作范式：不写剧本，设定规则看涌现

三个场景用同一个引擎，差异只在配置。

二、核心理念：蜂群涌现

为什么不让 AI 写剧本？

传统 AI 叙事

一个 LLM 编写故事 = 本质上是一个人在写作

Dreamina 的方案

多个独立 AI Agent 各自行动 = 本质上是一个社会在运转

"蜂群没有指挥官，却能建造精密的蜂巢。
人类社会没有编剧，却产生了无数精彩的故事。"

原因只有两个：

  1. 每个个体都有自己的目标
  2. 资源永远不够分

冲突、合作、背叛、牺牲——全部从这两个简单条件自然涌现。

V1 的问题：伪多智能体

V1 用一次 LLM 调用同时决定所有 NPC 的行为——本质上是一个大脑在控制所有角色。

  • LLM 作为统一意识，天然"读心"——NPC A 做决策时其实知道 NPC B 在想什么
  • 信息不对称无法真正实现
  • 每个 NPC 分到的思考深度被摊薄

V2 的核心升级：真多智能体

每个 NPC = 一个独立的 AI Agent，拥有：

  • 独立的 LLM 调用（自己的"大脑"）
  • 独立的记忆系统（只记得自己经历的）
  • 独立的视角（只看到自己能看到的）
  • 独立的判断（可能是错的，可能被骗）

三、行业调研：三大系统的对比与借鉴

3.1 斯坦福小镇 (Generative Agents, 2023)

斯坦福与 Google 合作的经典论文。25 个 AI Agent 在虚拟小镇中自主生活，涌现出情人节派对、竞选等社会行为。

核心机制：

  • 每个 Agent 独立运行，有自己的记忆流（Memory Stream）
  • 记忆检索基于三因子：时间衰减 × 重要性 × 相关性
  • 定期"反思"：从具体事件中归纳出抽象认知
  • 层级规划：日计划 → 小时计划 → 分钟级行动

借鉴 记忆检索机制、反思机制

差异 Dreamina 有量化基因系统、双层关系（城府机制）、资源稀缺驱动

3.2 Mem0 记忆架构 (2024-2025)

AI 记忆领域的前沿开源项目，在 LOCOMO 基准上比 OpenAI 内置记忆提升 26%。

核心机制：

  • 记忆写入不是简单追加，而是决策流水线：提取 → 比对 → ADD/UPDATE/DELETE/NOOP
  • 矛盾检测：新旧信息冲突时 LLM 判断保留哪个
  • 战略性遗忘：记太多是噪音污染，主动遗忘不重要的信息

借鉴 记忆写入流水线、矛盾检测、战略性遗忘

创新 记忆能力受基因调制（不同性格的 NPC 记忆能力不同）

3.3 Claude Agent Teams (Anthropic, 2025)

Anthropic 的多 Agent 协作框架。

核心机制：

  • 每个 Agent 是独立进程，拥有独立上下文窗口
  • Pull-based 任务认领：Agent 自主认领，非中央分配
  • 异步邮箱通信：通过消息传递，没有共享内存
  • 设计哲学：显式通信优于共享状态

借鉴 独立 Agent 并行架构、异步通信机制

差异 Dreamina Agent 有持久记忆和人格，不是无状态工具

3.4 认知科学基础

人类认知特征Dreamina V2 对应设计
情景记忆 vs 语义记忆 (Tulving)两层记忆：事件记录 + 归纳出的知识/信念
遗忘曲线 (Ebbinghaus)指数衰减，重要性和情绪强度调制衰减速率

工作记忆容量限制 (Baddeley)每次决策只能调用有限条相关记忆

3.5 学术论据：多智能体创造力 > 单智能体

核心论点：创作型 Agent 的架构应该是"蜂群"去中心化的 Multi-Agent，而不是 Sub-Agent 层级调用。学术研究表明，多个独立 Agent 协作的创造力显著优于单 Agent 或层级式 Sub-Agent。

关键论文 #1：Creativity in LLM-based Multi-Agent Systems: A Survey
Lin et al., EMNLP 2025 · 台湾大学 & 李宏毅团队 · arXiv 2505.21116

首篇系统性研究 LLM 多智能体创造力的综述论文。核心结论：

  • "协作结构能释放超越孤立 LLM 或个体所能达到的创造潜力"（collaborative structures can unlock creative potentials that exceed what isolated LLMs can achieve）
  • 提出了 Agent 主动性分类框架（Planning / Process / Decision-Making 三阶段），发现现有系统在规划阶段的 Agent 主动性普遍偏低——意味着多智能体的创造力潜力尚未被充分挖掘
  • 多 Agent 的角色多样性（persona diversity）是创造力提升的关键因素

关键论文 #2：Agents' Room — Narrative Generation through Multi-step Collaboration
Huot et al. (Google DeepMind), ICLR 2025 · arXiv 2410.02603

多 Agent 协作写故事 vs 单 Agent 写故事的直接对比实验：

  • 架构：规划 Agent 组（冲突、情节、角色、场景）+ 写作 Agent 组（起承转合结）+ 协调器 + 共享草稿板
  • 人类专家评估：多 Agent 在所有四个维度上优于单 Agent，其中创造力维度的优势最大
  • 多 Agent 生成的文本与 prompt 的重复度更低（类似人类写作的创造性发散），单 Agent 则倾向于复述 prompt

关键论文 #3：Exploring Design of Multi-Agent LLM Dialogues for Research Ideation
Ueda et al., SIGDIAL 2025 · arXiv 2507.08350

系统性实验探索了多 Agent 创意生成的最优配置：

  • 测试了 7 种对话配置 × 7 个研究主题
  • 最优配置：3 个并行批评者 + 2-3 轮迭代深化
  • 增加 Agent 多样性 → 提升创意多样性；增加迭代深度 → 提升创意质量且不损害多样性
  • 角色异质性（不同专长、不同视角）是关键——这正是 Dreamina 基因系统的设计初衷

关键论文 #4：Towards a Science of Scaling Agent Systems
Google Research & DeepMind & MIT, 2025 · arXiv 2512.08296

180 组对照实验，5 种架构，3 家 LLM，最严谨的多 Agent 规模化研究：

  • 可并行任务：多 Agent 比单 Agent 提升 80.9%（集中式协调）
  • 45% 阈值规则：单 Agent 准确率低于 45% 时，多 Agent 协调收益 > 协调成本
  • 模型异质性（混合不同模型）普遍提升多 Agent 效果——支持 Dreamina "不同基因 = 不同认知方式"的设计

对 Dreamina 的启示：

学术发现Dreamina V2 的对应设计
多 Agent 协作创造力 > 单 Agent每个 NPC 独立 Agent，不是一个 LLM 演所有人
角色多样性是创造力关键基因系统量化性格差异，确保每个 Agent 视角不同
迭代深度提升质量动态对话轮次（有话继续聊），不是固定一轮
并行 + 协调优于层级调用NPC 并行决策 + 世界引擎协调，不是 Sub-Agent 层级
模型异质性提升效果不同基因 = 不同认知风格 = 天然异质性

3.6 为什么"预测下一帧"和 Sub-Agent 出不来真正的创意

当前 AI 内容生成有两条主流路线，我们认为它们都有根本性的创造力天花板：

路线 A："预测下一帧"（Sora、Runway 等视频生成）

核心算法：给定前 N 帧，预测第 N+1 帧。本质是在训练数据的分布内做统计外推。

问题：最可能的下一帧，恰恰是最没创意的下一帧。

创意的定义就是"出人意料"。但预测模型的优化目标是"最大似然"——它永远在追求最可能发生的事。

它能生成视觉上惊艳的画面，但不能生成叙事上出人意料的转折。它是高级插值，不是创造。
  • 没有意图：模型不知道角色"想要什么"，只知道像素统计规律
  • 没有冲突：没有多个目标在竞争，就没有戏剧张力的来源
  • 没有信息不对称：模型是全知的，没有"角色 A 不知道角色 B 的秘密"这种结构
  • 没有涌现：输出完全被输入决定，不可能产生超出训练分布的新模式

类比：让一个人看了一万部电影，然后让他"预测下一个镜头"——他会给出一个合理的镜头，但不会给出一个伟大的镜头。伟大的镜头来自导演的意图、角色的冲突、观众的期待被打破。

路线 B：Sub-Agent 层级调用（单脑多手）

架构：一个主 Agent 拆解任务，分派给多个 Sub-Agent 执行，汇总结果。

问题：Sub-Agent 是"手"，不是"脑"。创意的天花板 = 主 Agent 一个人的想象力。
维度Sub-Agent（层级式）Multi-Agent（蜂群式）
谁在思考？ 只有主 Agent 在思考，Sub-Agent 执行指令 每个 Agent 都在独立思考，有自己的判断
信息对称性 主 Agent 全知，Sub-Agent 只知道被分配的部分 每个 Agent 只知道自己看到的——误解和信息差产生意外
能否产生分歧？ 不能。Sub-Agent 服从主 Agent 的规划 天然产生分歧——分歧是创意的来源
意外/惊喜 不可能。输出完全在主 Agent 的预期内 常态。独立 Agent 的行为组合产生谁都没预料到的结果
创意天花板 = 主 Agent 的能力上限 = 所有 Agent 能力的涌现组合，理论上无上限
类比 一个导演指挥群演——导演想到哪，故事就到哪 一群真人在即兴表演——连演员自己都不知道下一秒会发生什么

Sub-Agent 模式的根本问题是单点创意瓶颈：

  1. 主 Agent 先想好了故事大纲（创意已经被锁定）
  2. Sub-Agent 只是在执行大纲（写第一章、写第二章...）
  3. 任何 Sub-Agent 都不会挑战主 Agent 的规划
  4. 最终产出 = 一个人的想法被多手执行，不会产生超出规划的涌现

Dreamina 的路线：多智能体涌现

我们不预测下一帧，也不用一个脑指挥多只手。我们让多个独立的脑各自行动：

为什么能产生真创意？

  • 每个 Agent 有独立目标 → 目标冲突产生戏剧
  • 每个 Agent 信息有限 → 误解驱动意外
  • 每个 Agent 性格不同 → 反应差异产生多样性
  • 没有全知的编剧 → 连系统自己都不知道下一步会发生什么

创意的涌现公式

独立目标
+ 有限信息
+ 性格差异
+ 资源稀缺
= 冲突、合作、背叛、牺牲自然涌现

不是编出来的，是长出来的。
不是一个人的想象力，是一个社会的复杂性。

四、产品方案

4.1 元系统架构：两层 Agent 体系

Dreamina 不只是"一堆 NPC 在跑"。它是一个元系统——由系统级 Agent 动态生成和管理 NPC Agent：

用户输入: "创建一个股票市场博弈世界"

         ┌──────────▼──────────┐
         │  🧠 世界分析师 Agent  │  ← 系统级 Agent #1
         │  分析世界类型          │
         │  预测型？叙事型？混合？ │
         │  需要联网感知吗？       │
         └──────────┬──────────┘
                    │
         ┌──────────▼──────────┐
         │  🏗️ 世界构建师 Agent │  ← 系统级 Agent #2
         │  生成世界规则和资源    │
         │  决定需要几个NPC      │
         │  分配基因和角色        │
         └──────────┬──────────┘
                    │
         ┌──────────▼──────────┐
         │  🎬 导演 Agent       │  ← 系统级 Agent #3（常驻）
         │  编排叙事、捕捉信息差  │
         │  制造天命事件          │
         └──────────┬──────────┘
                    │
         ┌─────┐ ┌─────┐ ┌─────┐   ← 动态生成的 NPC Agents

两层 Agent 的区别：

层级Agent职责生命周期
系统级世界分析师理解用户意图，判断世界类型和配置创建阶段，一次性
系统级世界构建师生成规则、资源、NPC 角色和基因创建阶段，一次性
系统级导演叙事合成、信息差捕捉、天命干预常驻，贯穿整个模拟
NPC 级每个角色独立决策、对话、记忆、行动常驻，可被导演创建/移除

系统级 Agent 是基础设施——用户不直接看到它们的运行过程，只看到它们的产出（一个完整的世界、一段精彩的叙事）。NPC Agent 是演员——用户可以观察、跟随、与之对话。

4.3 基因系统：量化灵魂

每个 NPC 的性格由 4 维基因向量定义（值域 0-1），不是文本标签。

基因不仅决定行为倾向，还决定认知能力（V2 新增）：

基因影响行为影响认知（V2 新增）
逻辑天赋分析问题的能力记忆重要性评估的准确度
敏感度情绪反应强度情绪事件记得更牢，但细节可能失真
理性 vs 感性决策偏好回忆偏向还原事实 vs 强化情绪
风险偏好冒险 vs 保守高 = 容易忘失败教训，低 = 记仇
共情天赋社交能力高 = 记住情绪细节，低 = 只记事实

同一事件，不同基因的 NPC 会记住不同的内容、以不同的速度遗忘、回忆时产生不同的扭曲。

4.3 认知记忆：像人一样记忆和遗忘

两层记忆：

  • 情景记忆 —— 亲身经历的事件，带时间、地点、情绪、信息来源标签
  • 语义记忆 —— 从经历中归纳出的知识和信念（如"李四不可靠"）

记忆写入不是简单追加，而是智能流水线：

新信息 → 提取关键事实 → 与已有记忆比对 → ADD / UPDATE / DELETE / NOOP

战略性遗忘：

  • 不重要的事自然遗忘（Ebbinghaus 衰减）
  • 情绪强烈的事记得更牢
  • 反复回忆的事不容易忘
  • 不同性格遗忘速度不同（大大咧咧的人会忘掉重要的事——这是合理的）
同一事件三个视角：

客观事实：李四对张三撒谎说"项目没问题"
张三记忆："李四说项目没问题"
王五记忆："听到李四跟张三说没问题，但他表情不自然"
李四记忆："我骗了张三"

记忆面板：用户可以看到每个 NPC 记住了什么、忘了什么。模拟过程透明可观察。

4.4 通信机制：真正的信息不对称

NPC 只能通过以下方式获取信息：

  1. 感知（被动）—— 看到同地点的人在做什么
  2. 对话（主动）—— 对方可能说真话、假话、或不说
  3. 传闻（间接）—— 经过传递的信息可能失真

对话是真正的交互——每句话是一次独立 LLM 调用，说话者不知道听者在想什么。有话继续聊，没话自然停止。

资源争夺不由系统裁决，而是让 NPC 各自执行策略——谈判、抢占、求助、让步——策略本身就是涌现的一部分。

4.5 导演系统：上帝视角的叙事编辑

独立 Agent，拥有上帝视角，负责：

  • 从多个 NPC 的行为中捕捉最有戏剧性的信息差和冲突
  • 合成图文交织的叙事流
  • 主动制造"天命"事件推动剧情（用户可开关）

天命干预：当世界趋于平淡时注入突发事件——暴风雨、新角色出现、关键资源枯竭。类似真实世界的"黑天鹅事件"。

4.6 感知适配器：虚拟与现实的桥梁

核心问题：这个世界里的 NPC 能不能"上网"？

模式含义场景
virtualNPC 只感知虚拟世界内部信息哈利波特、办公室模拟
realworldNPC 可获取真实世界信息（联网搜索）股票预测、球赛推演
hybrid虚构世界观 + 真实信息流浪地球（虚构 + 真实物理）

4.7 图片一致性 & 流式体验

  • 每个角色创建时生成"定妆照"，每个场景生成"基准图"
  • 后续图片通过图生图保持视觉一致性
  • 文本通过 SSE 实时推送，图片异步生成后插入叙事流
  • 用户感受：打开世界后，内容持续涌现，永远有新东西出现

五、交互设计：用户怎么用

这不是换一个皮肤。多智能体世界模拟需要全新的交互范式——用户要能创建世界、观察多 Agent 运行、切换视角、干预剧情。

5.1 创建世界：对话式 + 渐进生成

用户不填表单，而是和世界分析师对话：

用户："我想看哈利波特毕业五年后的故事"
分析师："好的，这是一个叙事模拟世界。你希望聚焦哪些角色？还是让我自动选择关键角色？"
用户："Harry、Hermione、Draco 必须有，其他你来定"
分析师："了解。我会加入 Ron、Ginny、Neville，以及一个新角色制造冲突。世界构建师正在生成..."

→ 世界构建师在后台生成规则、资源、角色基因、关系网
→ 生成过程中，角色定妆照和场景基准图同步生成
→ 用户看到角色卡片逐一出现，可以点击调整

用户也可以跳过对话，直接选择预设世界模板或上传自定义配置。

5.2 观察运行：三种视角

视角用户看到什么适合场景
上帝视角
(导演叙事)		 导演 Agent 合成的全局叙事流。能看到所有人的行为，信息差被高亮揭示（"张三不知道的是，李四正在背后..."）。图文交织，最有戏剧性。 休闲观看，追故事
跟随视角
(NPC 主观)		 只看到某个 NPC 知道的信息。TA 的内心独白、TA 看到的世界、TA 记住的事。其他人对 TA 的算计，TA 看不到。 沉浸体验，角色代入
全景视角
(系统监控)		 所有 Agent 的实时状态面板：位置、记忆变化、关系网、张力图。像控制台一样看到整个系统在运转。 调试、研究、预测分析

用户可以随时在三种视角之间切换。跟随视角可以点击任意 NPC 切换跟随对象。

5.3 记忆面板：透视 NPC 的认知

点击任意 NPC，展开记忆面板：

情景记忆

按时间倒序排列，颜色表示情绪强度

  • ● tick 24: "老板当众批评了我的方案" importance: 9
  • ● tick 22: "听王五说李四在背后说我坏话" 来源: 传闻
  • ● tick 18: "在茶水间喝了咖啡" importance: 2 ⚡即将遗忘

语义记忆（信念）

从经历中归纳出的认知

  • "老板对我有偏见" 置信度: 0.7
  • "李四不可靠" 置信度: 0.5
  • "王五是可以信任的" 置信度: 0.8

用户可以看到记忆的来源标签（亲眼看到 / 别人说的 / 推测），以及哪些记忆即将被遗忘、哪些被反思强化。这让模拟过程透明可观察。

5.4 天命干预：用户掌控世界命运

两种干预方式：

手动干预

用户从天命控制台直接注入事件：

  • "突然停电，所有人被困在办公室"
  • "新角色空降：一个神秘的实习生"
  • "CEO 宣布裁员 30%"

事件注入后，NPC Agent 各自独立反应

导演自动干预

当导演 Agent 检测到世界趋于平淡（张力持续走低），自动提议天命事件：

🎬 导演提议："故事最近比较平淡，建议触发'机密文件泄露'事件？"
[✅ 同意]   [❌ 拒绝]   [✏️ 修改]

用户可以关闭导演自动干预权限

5.5 与 NPC 对话：上帝降临

用户可以随时和任意 NPC 对话。NPC 不知道对方是"上帝"——就当是在和一个普通人聊天。

对话可以影响 NPC 的记忆和判断（用户选择是否写入记忆），也可以纯粹旁观（不影响世界状态）。

5.6 流式体验：世界永远在动

不是"点一下等 10 秒看结果"。用户打开世界后：

  • NPC 对话实时逐句出现（像微信聊天记录在刷屏）
  • 导演旁白流式推送（字一个一个出来）
  • 场景图片异步加载（先占位，生成完毕自动替换）
  • 下一个时间段在当前段展示完毕前就开始准备

用户感受：打开世界后，内容持续涌现，永远有新东西出现。

六、为什么这个方向有价值

对 AI 叙事

现有工具（NovelAI、AI Dungeon）= 一个 LLM 写故事

Dreamina = 多个 Agent 演故事

单 LLM 的故事是"编"出来的，多 Agent 涌现的故事是"长"出来的。后者的不可预测性和真实感是前者无法达到的。

对群体预测

现有 AI = 一个模型给一个答案

Dreamina = 多个 Agent 各自分析博弈

让"保守分析师"和"激进交易员"各自判断，结果比单一模型更接近真实市场的复杂性。

对 UGC 创作

现有 UGC = 用户写内容。Dreamina = 用户设定规则，AI 演绎内容。

这是内容创作的新范式：创作者不再是"写故事的人"，而是"造世界的人"。门槛更低，可能性更大。
