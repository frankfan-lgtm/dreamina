Dreamina V2

AI 通用多智能体世界模拟引擎 — 设计理念与产品方案

一、我们在做什么

一句话：用户描述一个世界，AI 自动生成角色和规则，每个角色作为独立智能体自主行动，故事从规则中自然涌现。

不是 AI 写剧本，是 AI 演活人。

三大应用场景：

场景示例用户价值
叙事模拟哈利波特毕业后的故事、流浪地球三以上帝/跟随视角看 AI 演绎的故事，可随时干预
群体预测模拟股票市场多方博弈、球赛推演多个"分析师 Agent"各自判断，涌现群体智慧
UGC 创作用户自定义世界观和角色新一代内容创作范式：不写剧本，设定规则看涌现

三个场景用同一个引擎，差异只在配置。

二、核心理念：蜂群涌现

为什么不让 AI 写剧本？

传统 AI 叙事

一个 LLM 编写故事 = 本质上是一个人在写作

Dreamina 的方案

多个独立 AI Agent 各自行动 = 本质上是一个社会在运转

"蜂群没有指挥官，却能建造精密的蜂巢。
人类社会没有编剧，却产生了无数精彩的故事。"

原因只有两个：

  1. 每个个体都有自己的目标
  2. 资源永远不够分

冲突、合作、背叛、牺牲——全部从这两个简单条件自然涌现。

V1 的问题：伪多智能体

V1 用一次 LLM 调用同时决定所有 NPC 的行为——本质上是一个大脑在控制所有角色。

  • LLM 作为统一意识，天然"读心"——NPC A 做决策时其实知道 NPC B 在想什么
  • 信息不对称无法真正实现
  • 每个 NPC 分到的思考深度被摊薄

V2 的核心升级：真多智能体

每个 NPC = 一个独立的 AI Agent，拥有：

  • 独立的 LLM 调用（自己的"大脑"）
  • 独立的记忆系统（只记得自己经历的）
  • 独立的视角（只看到自己能看到的）
  • 独立的判断（可能是错的，可能被骗）

三、行业调研：三大系统的对比与借鉴

3.1 斯坦福小镇 (Generative Agents, 2023)

斯坦福与 Google 合作的经典论文。25 个 AI Agent 在虚拟小镇中自主生活，涌现出情人节派对、竞选等社会行为。

核心机制：

  • 每个 Agent 独立运行，有自己的记忆流（Memory Stream）
  • 记忆检索基于三因子：时间衰减 × 重要性 × 相关性
  • 定期"反思"：从具体事件中归纳出抽象认知
  • 层级规划：日计划 → 小时计划 → 分钟级行动

借鉴 记忆检索机制、反思机制

差异 Dreamina 有量化基因系统、双层关系（城府机制）、资源稀缺驱动

3.2 Mem0 记忆架构 (2024-2025)

AI 记忆领域的前沿开源项目，在 LOCOMO 基准上比 OpenAI 内置记忆提升 26%。

核心机制：

  • 记忆写入不是简单追加，而是决策流水线：提取 → 比对 → ADD/UPDATE/DELETE/NOOP
  • 矛盾检测：新旧信息冲突时 LLM 判断保留哪个
  • 战略性遗忘：记太多是噪音污染，主动遗忘不重要的信息

借鉴 记忆写入流水线、矛盾检测、战略性遗忘

创新 记忆能力受基因调制（不同性格的 NPC 记忆能力不同）

3.3 Claude Agent Teams (Anthropic, 2025)

Anthropic 的多 Agent 协作框架。

核心机制：

  • 每个 Agent 是独立进程，拥有独立上下文窗口
  • Pull-based 任务认领：Agent 自主认领，非中央分配
  • 异步邮箱通信：通过消息传递，没有共享内存
  • 设计哲学：显式通信优于共享状态

借鉴 独立 Agent 并行架构、异步通信机制

差异 Dreamina Agent 有持久记忆和人格，不是无状态工具

3.4 认知科学基础

人类认知特征Dreamina V2 对应设计
情景记忆 vs 语义记忆 (Tulving)两层记忆：事件记录 + 归纳出的知识/信念
遗忘曲线 (Ebbinghaus)指数衰减，重要性和情绪强度调制衰减速率
情绪增强记忆情绪越强的事记得越牢，但细节可能不准确
记忆重构性每次回忆受当前情绪和目标影响，不是完美回放
来源监控追踪"亲眼看到" vs "听说的"，影响可信度
工作记忆容量限制 (Baddeley)每次决策只能调用有限条相关记忆

4.2 基因系统：量化灵魂

每个 NPC 的性格由 4 维基因向量定义（值域 0-1），不是文本标签。

基因不仅决定行为倾向，还决定认知能力（V2 新增）：

基因影响行为影响认知（V2 新增）
逻辑天赋分析问题的能力记忆重要性评估的准确度
敏感度情绪反应强度情绪事件记得更牢，但细节可能失真
理性 vs 感性决策偏好回忆偏向还原事实 vs 强化情绪
风险偏好冒险 vs 保守高 = 容易忘失败教训，低 = 记仇
共情天赋社交能力高 = 记住情绪细节，低 = 只记事实

同一事件，不同基因的 NPC 会记住不同的内容、以不同的速度遗忘、回忆时产生不同的扭曲。

4.3 认知记忆：像人一样记忆和遗忘

两层记忆：

  • 情景记忆 —— 亲身经历的事件，带时间、地点、情绪、信息来源标签
  • 语义记忆 —— 从经历中归纳出的知识和信念（如"李四不可靠"）

记忆写入不是简单追加，而是智能流水线：

新信息 → 提取关键事实 → 与已有记忆比对 → ADD / UPDATE / DELETE / NOOP

战略性遗忘：

  • 不重要的事自然遗忘（Ebbinghaus 衰减）
  • 情绪强烈的事记得更牢
  • 反复回忆的事不容易忘
  • 不同性格遗忘速度不同（大大咧咧的人会忘掉重要的事——这是合理的）
同一事件三个视角：

客观事实：李四对张三撒谎说"项目没问题"
张三记忆："李四说项目没问题"
王五记忆："听到李四跟张三说没问题，但他表情不自然"
李四记忆："我骗了张三"

记忆面板：用户可以看到每个 NPC 记住了什么、忘了什么。模拟过程透明可观察。

4.4 通信机制：真正的信息不对称

NPC 只能通过以下方式获取信息：

  1. 感知（被动）—— 看到同地点的人在做什么
  2. 对话（主动）—— 对方可能说真话、假话、或不说
  3. 传闻（间接）—— 经过传递的信息可能失真

对话是真正的交互——每句话是一次独立 LLM 调用，说话者不知道听者在想什么。有话继续聊，没话自然停止。

资源争夺不由系统裁决，而是让 NPC 各自执行策略——谈判、抢占、求助、让步——策略本身就是涌现的一部分。

4.5 导演系统：上帝视角的叙事编辑

独立 Agent，拥有上帝视角，负责：

  • 从多个 NPC 的行为中捕捉最有戏剧性的信息差和冲突
  • 合成图文交织的叙事流
  • 主动制造"天命"事件推动剧情（用户可开关）

天命干预：当世界趋于平淡时注入突发事件——暴风雨、新角色出现、关键资源枯竭。类似真实世界的"黑天鹅事件"。

4.6 感知适配器：虚拟与现实的桥梁

核心问题：这个世界里的 NPC 能不能"上网"？

模式含义场景
virtualNPC 只感知虚拟世界内部信息哈利波特、办公室模拟
realworldNPC 可获取真实世界信息（联网搜索）股票预测、球赛推演
hybrid虚构世界观 + 真实信息流浪地球（虚构 + 真实物理）

4.7 图片一致性 & 流式体验

  • 每个角色创建时生成"定妆照"，每个场景生成"基准图"
  • 后续图片通过图生图保持视觉一致性
  • 文本通过 SSE 实时推送，图片异步生成后插入叙事流
  • 用户感受：打开世界后，内容持续涌现，永远有新东西出现

五、为什么这个方向有价值

对 AI 叙事

现有工具（NovelAI、AI Dungeon）= 一个 LLM 写故事

Dreamina = 多个 Agent 演故事

单 LLM 的故事是"编"出来的，多 Agent 涌现的故事是"长"出来的。后者的不可预测性和真实感是前者无法达到的。

对群体预测

现有 AI = 一个模型给一个答案

Dreamina = 多个 Agent 各自分析博弈

让"保守分析师"和"激进交易员"各自判断，结果比单一模型更接近真实市场的复杂性。

对 UGC 创作

现有 UGC = 用户写内容。Dreamina = 用户设定规则，AI 演绎内容。

这是内容创作的新范式：创作者不再是"写故事的人"，而是"造世界的人"。门槛更低，可能性更大。
