# Dreamina V2 —— AI 通用多智能体世界模拟引擎

> 设计理念与产品方案

---

## 一、我们在做什么

**一句话**：用户描述一个世界，AI 自动生成角色和规则，每个角色作为独立智能体自主行动，故事从规则中自然涌现。

不是 AI 写剧本，是 AI 演活人。

**三大应用场景**：

| 场景 | 示例 | 用户价值 |
|------|------|----------|
| 叙事模拟 | 哈利波特毕业后的故事、流浪地球三 | 用户以上帝/跟随视角看 AI 演绎的故事，可随时干预 |
| 群体预测 | 模拟股票市场多方博弈、球赛推演 | 多个"分析师 Agent"各自判断，涌现出群体智慧 |
| UGC 创作 | 用户自定义世界观和角色 | 新一代内容创作范式：不写剧本，而是设定规则看涌现 |

三个场景用同一个引擎，差异只在配置。

## 二、核心理念：蜂群涌现

### 为什么不让 AI 写剧本？

传统 AI 叙事 = 一个 LLM 编写故事 = 本质上是一个人在写作。

我们的方案 = 多个独立 AI Agent 各自行动 = 本质上是一个社会在运转。

**蜂群没有指挥官，却能建造精密的蜂巢。** 人类社会没有编剧，却产生了无数精彩的故事。原因只有两个：

1. **每个个体都有自己的目标**
2. **资源永远不够分**

冲突、合作、背叛、牺牲——全部从这两个简单条件自然涌现。

### V1 的问题

V1 用一次 LLM 调用同时决定所有 NPC 的行为。这是**伪多智能体**——本质上还是一个大脑在控制所有角色。

后果：
- LLM 作为统一意识，天然"读心"——NPC A 做决策时其实知道 NPC B 在想什么
- 信息不对称无法真正实现
- 每个 NPC 分到的思考深度被摊薄

### V2 的核心升级

**每个 NPC = 一个独立的 AI Agent**，拥有：
- 独立的 LLM 调用（自己的"大脑"）
- 独立的记忆系统（只记得自己经历的）
- 独立的视角（只看到自己能看到的）
- 独立的判断（可能是错的，可能被骗）

## 三、行业调研：三大系统的对比与借鉴

我们系统性研究了三个代表性系统，提炼出 Dreamina V2 的设计方案。

### 3.1 斯坦福小镇 (Generative Agents, 2023)

斯坦福与 Google 合作的经典论文。25 个 AI Agent 在虚拟小镇中自主生活，涌现出了情人节派对、竞选等社会行为。

**核心机制**：
- 每个 Agent 独立运行，有自己的记忆流（Memory Stream）
- 记忆检索基于三个因子：时间衰减 × 重要性 × 相关性
- 定期"反思"：从具体事件中归纳出抽象认知
- 层级规划：日计划 → 小时计划 → 分钟级行动

**我们借鉴**：记忆检索机制、反思机制
**我们的差异**：Dreamina 有量化基因系统（性格不是纯文本描述）、双层关系系统（城府机制）、资源稀缺驱动

### 3.2 Mem0 记忆架构 (2024-2025)

AI 记忆领域的前沿开源项目，在 LOCOMO 基准测试上比 OpenAI 内置记忆提升 26%。

**核心机制**：
- 记忆写入不是简单追加，而是一个决策流水线：提取 → 比对已有记忆 → 决定 ADD/UPDATE/DELETE/NOOP
- 矛盾检测：新信息与旧记忆冲突时，LLM 判断保留哪个
- 战略性遗忘：记太多是噪音污染，主动遗忘不重要的信息

**我们借鉴**：记忆写入流水线、矛盾检测、战略性遗忘
**我们的创新**：记忆能力受基因调制（不同性格的 NPC 记忆能力不同）

### 3.3 Claude Agent Teams (Anthropic, 2025)

Anthropic 的多 Agent 协作框架，用于软件工程任务。

**核心机制**：
- 每个 Agent 是独立进程，拥有独立的上下文窗口
- Pull-based 任务认领：不是中央分配，而是 Agent 自主认领
- 异步邮箱通信：Agent 之间通过消息传递信息，没有共享内存
- 设计哲学：**显式通信优于共享状态**

**我们借鉴**：独立 Agent 并行架构、异步通信机制
**我们的差异**：Dreamina Agent 有持久记忆和人格，不是无状态工具

### 3.4 认知科学基础

| 人类认知特征 | Dreamina V2 的对应设计 |
|-------------|----------------------|
| 情景记忆 vs 语义记忆 (Tulving) | 两层记忆：事件记录 + 归纳出的知识/信念 |
| 遗忘曲线 (Ebbinghaus) | 指数衰减，重要性和情绪强度调制衰减速率 |
| 情绪增强记忆 | 情绪越强的事记得越牢，但细节可能不准确 |
| 记忆重构性 | 每次回忆受当前情绪和目标影响，不是完美回放 |
| 来源监控 | 追踪信息来源："亲眼看到" vs "听说的"，影响可信度 |
| 工作记忆容量限制 (Baddeley) | 每次决策只能调用有限条相关记忆 |

## 四、产品方案

### 4.1 元系统架构：两层 Agent 体系

Dreamina 不只是"一堆 NPC 在跑"。它是一个**元系统**——由系统级 Agent 动态生成和管理 NPC Agent：

```
用户输入: "创建一个股票市场博弈世界"
                    │
         ┌──────────▼──────────┐
         │  🧠 世界分析师 Agent  │  ← 系统级 Agent #1
         │  分析世界类型          │
         │  预测型？叙事型？混合？ │
         │  需要联网感知吗？       │
         └──────────┬──────────┘
                    │
         ┌──────────▼──────────┐
         │  🏗️ 世界构建师 Agent │  ← 系统级 Agent #2
         │  生成世界规则和资源    │
         │  决定需要几个NPC      │
         │  分配基因和角色        │
         └──────────┬──────────┘
                    │
         ┌──────────▼──────────┐
         │  🎬 导演 Agent       │  ← 系统级 Agent #3（常驻）
         │  编排叙事、捕捉信息差  │
         │  制造天命事件          │
         └──────────┬──────────┘
                    │
         ┌─────┐ ┌─────┐ ┌─────┐   ← 动态生成的 NPC Agents
         │NPC-A│ │NPC-B│ │ ... │      数量由世界构建师决定
         └─────┘ └─────┘ └─────┘
```

**两层 Agent 的区别：**

| 层级 | Agent | 职责 | 生命周期 |
|------|-------|------|---------|
| **系统级** | 世界分析师 | 理解用户意图，判断世界类型和配置 | 创建阶段，一次性 |
| **系统级** | 世界构建师 | 生成规则、资源、NPC 角色和基因 | 创建阶段，一次性 |
| **系统级** | 导演 | 叙事合成、信息差捕捉、天命干预 | 常驻，贯穿整个模拟 |
| **NPC 级** | 每个角色 | 独立决策、对话、记忆、行动 | 常驻，可被导演创建/移除 |

系统级 Agent 是**基础设施**——用户不直接看到它们的运行过程，只看到产出。NPC Agent 是**演员**——用户可以观察、跟随、对话。

### 4.2 完整系统架构

```
┌─ 用户交互层 ────────────────────────────────┐
│  世界创建 · 多视角观察 · 天命干预 · NPC 对话   │
└──────────────────┬──────────────────────────┘
                   │
┌──────────────────▼──────────────────────────┐
│  系统级 Agent 层                              │
│  🧠 世界分析师 → 🏗️ 世界构建师 → 🎬 导演     │
└──────────────────┬──────────────────────────┘
                   │
┌──────────────────▼──────────────────────────┐
│  世界引擎：物理约束 · 通信总线 · 资源管理       │
└──────────────────┬──────────────────────────┘
                   │
┌──────────────────▼──────────────────────────┐
│  NPC Agent 层（动态生成，数量由构建师决定）     │
│  每个 NPC = 独立 LLM + 独立记忆 + 独立视角    │
└──────────────────┬──────────────────────────┘
                   │
┌──────────────────▼──────────────────────────┐
│  认知记忆 · 感知适配器（virtual/realworld）    │
└─────────────────────────────────────────────┘
```

### 4.4 基因系统：量化灵魂

每个 NPC 的性格由 4 维基因向量定义（值域 0-1），不是文本标签。

基因不仅决定**行为倾向**，还决定**认知能力**：

| 基因 | 影响行为 | 影响认知（V2 新增） |
|------|---------|-------------------|
| 逻辑天赋 | 分析问题的能力 | 记忆重要性评估的准确度 |
| 敏感度 | 情绪反应强度 | 情绪事件记得更牢，但细节可能失真 |
| 理性 vs 感性 | 决策偏好 | 回忆时偏向还原事实 vs 强化情绪 |
| 风险偏好 | 冒险 vs 保守 | 高=容易忘记失败教训，低=记仇 |
| 共情天赋 | 社交能力 | 高=记住别人的情绪细节，低=只记事实 |

同一个事件，不同基因的 NPC 会**记住不同的内容、以不同的速度遗忘、回忆时产生不同的扭曲**。

### 4.5 认知记忆：像人一样记忆和遗忘

**两层记忆**：

- **情景记忆**：亲身经历的事件，带时间、地点、情绪、信息来源标签
- **语义记忆**：从经历中归纳出的知识和信念（如"李四不可靠"）

**记忆写入**不是简单追加，而是智能流水线：
```
新信息 → 提取关键事实 → 与已有记忆比对 → ADD/UPDATE/DELETE/NOOP
```

**战略性遗忘**：
- 不重要的事自然遗忘（Ebbinghaus 衰减）
- 情绪强烈的事记得更牢
- 反复回忆的事不容易忘
- 不同性格遗忘速度不同（大大咧咧的人会忘掉重要的事——这是合理的）

**记忆面板**：用户可以看到每个 NPC 记住了什么、忘了什么。这让模拟过程透明可观察。

**同一事件三个视角**：
```
客观事实：李四对张三撒谎说"项目没问题"
张三记忆："李四说项目没问题"
王五记忆："听到李四跟张三说没问题，但他表情不自然"
李四记忆："我骗了张三"
```

### 4.6 通信机制：真正的信息不对称

NPC 只能通过以下方式获取信息：
1. **感知**（被动）—— 看到同地点的人在做什么
2. **对话**（主动）—— 对方可能说真话、假话、或不说
3. **传闻**（间接）—— 经过传递的信息可能失真

对话是真正的交互——每句话是一次独立 LLM 调用，说话者不知道听者在想什么。有话就继续聊，没话自然停止。

资源争夺不由系统裁决，而是让 NPC 各自执行策略——谈判、抢占、求助、让步——策略本身就是涌现的一部分。

### 4.7 导演系统：上帝视角的叙事编辑

独立 Agent，拥有上帝视角，负责：
- 从多个 NPC 的行为中捕捉最有戏剧性的信息差和冲突
- 合成图文交织的叙事流
- 主动制造"天命"事件推动剧情（用户可开关）

**天命干预**：当世界运转趋于平淡时，导演可以注入突发事件——暴风雨、新角色出现、关键资源枯竭。类似真实世界的"黑天鹅事件"。

用户也可以手动注入天命，或者关闭导演的自动干预权限。

### 4.8 感知适配器：虚拟与现实的桥梁

核心问题：**这个世界里的 NPC 能不能"上网"？**

| 模式 | 含义 | 场景 |
|------|------|------|
| virtual | NPC 只感知虚拟世界内部信息 | 哈利波特、办公室模拟 |
| realworld | NPC 可获取真实世界信息（联网搜索） | 股票预测、球赛推演 |
| hybrid | 虚构世界观 + 真实信息 | 流浪地球（虚构+真实物理） |

由世界模板自动配置，用户可手动调整。

### 4.9 图片一致性系统

- 世界创建时为每个角色生成"定妆照"、每个场景生成"基准图"
- 后续场景图通过图生图保持角色和场景视觉一致性
- 图片 prompt 程序化组装（风格+角色+场景+动作），不手写
- 生成分辨率 2560x1440，显示缩小到 720P

### 4.10 流式体验：世界永远在动

- 文本通过 SSE 实时流式推送，永不出现空白等待
- 图片异步生成，完成后自动插入叙事流
- NPC 决策并行执行，对话实时推送
- 下一时段在当前时段展示完毕前就开始准备

用户感受：打开世界后，内容持续涌现，永远有新东西出现。

## 五、交互设计：用户怎么用

这不是换一个皮肤。多智能体世界模拟需要**全新的交互范式**。

### 5.1 创建世界：对话式 + 渐进生成

用户不填表单，而是**和世界分析师对话**：

> 用户："我想看哈利波特毕业五年后的故事"
> 分析师："好的，这是叙事模拟世界。你希望聚焦哪些角色？"
> 用户："Harry、Hermione、Draco 必须有，其他你来定"
> 分析师："了解。世界构建师正在生成..."
> → 角色卡片逐一出现，用户可点击调整

### 5.2 观察运行：三种视角

| 视角 | 用户看到什么 | 适合场景 |
|------|------------|---------|
| **上帝视角**（导演叙事） | 全局叙事流，信息差被高亮揭示（"张三不知道的是..."） | 休闲观看，追故事 |
| **跟随视角**（NPC 主观） | 只看到某个 NPC 知道的信息，TA 的内心独白和主观世界 | 沉浸体验，角色代入 |
| **全景视角**（系统监控） | 所有 Agent 实时状态面板：位置、记忆变化、关系网、张力图 | 调试、研究、预测分析 |

用户可随时切换视角，跟随视角可点击任意 NPC 切换跟随对象。

### 5.3 记忆面板：透视 NPC 的认知

点击任意 NPC 展开记忆面板：
- **情景记忆**：按时间倒序，颜色表示情绪强度，标注来源（亲眼看到/听说/推测），标记即将遗忘的记忆
- **语义记忆**：归纳出的信念，显示置信度（可被新证据更新）

### 5.4 天命干预

- **手动**：用户从天命控制台直接注入事件（"突然停电"、"新角色空降"）
- **自动**：导演检测到张力走低时提议天命事件，用户可同意/拒绝/修改。可关闭自动干预。

### 5.5 与 NPC 对话

用户随时和任意 NPC 对话。NPC 不知道对方是"上帝"。对话可选择是否写入 NPC 记忆。

### 5.6 流式体验

不是"点一下等 10 秒"。打开世界后：NPC 对话实时逐句出现，导演旁白流式推送，场景图片异步加载，下一时段提前准备。**世界永远在动。**

## 六、为什么这个方向有价值

### 5.1 对 AI 叙事

现有 AI 写作工具（NovelAI、AI Dungeon）= 一个 LLM 写故事。Dreamina = 多个 AI Agent 演故事。

区别：单 LLM 写出的故事是"编"出来的，多 Agent 涌现的故事是"长"出来的。后者的不可预测性和真实感是前者无法达到的。

### 5.2 对群体预测

现有 AI 预测 = 一个模型给一个答案。Dreamina = 多个 Agent 各自分析博弈。

区别：群体智慧 > 个体智慧。让"保守分析师"和"激进交易员"各自独立判断并博弈，结果比单一模型更接近真实市场的复杂性。

### 5.3 对 UGC 创作

现有 UGC = 用户写内容。Dreamina = 用户设定规则，AI 演绎内容。

这是内容创作的新范式：创作者不再是"写故事的人"，而是"造世界的人"。门槛更低，可能性更大。
